⏱ ±30 detik PESAN UTAMA: Data dicek dulu sebelum dipakai, terhubung ke sistem KKP, dan aman. UCAPKAN: "Setelah sampai di cloud, data tidak langsung dipercaya. Untuk peringatan biasa, sistem menunggu tiga bacaan berturut-turut, supaya petugas tidak dibanjiri alarm palsu. Prakiraan cuaca BMKG ikut dipakai untuk memperkirakan oksigen menjelang subuh. Data kemudian dikirim ke STELINA, SICEKATAN, dan Satu Data — melengkapi sistem KKP, bukan menggantikannya.
