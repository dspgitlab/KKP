Layer aplikasi punya tiga fungsi: dashboard untuk melihat data real-time dan histori, notifikasi saat ada pelanggaran ambang atau anomali, dan modul kontrol otomatis. Kontrol otomatis selalu bisa di-override petambak dari dashboard. Di layer aktuasi, perintah diteruskan ke relay atau kontaktor berpengaman fuse untuk menyalakan aerator dan pompa air.
